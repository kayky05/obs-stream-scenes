## Before recording or going live

1. Turn on Do Not Disturb so notifications never show on screen.
2. In browser screens, use **125% to 150% zoom**: the screen is scaled down inside the frame, and the
   zoom keeps text readable in the video.
3. If you also record the camera separately (phone, DSLR), **clap once** at the start: it becomes the
   sync point in the edit.
4. Check the starting scene and record (or go live).

Recordings go to `{{RECORDINGS}}`.

## If the kit folder moves

OBS points to these files by absolute path. If you move this folder, run the build again
(`build_kit.py` and `configure_obs.py`) so OBS finds the files in the new place.
